# SQI Tailwind Try

A responsive landing page for SQI College built to learn and practice Tailwind CSS.

## About

This project contains a simple static page in `try/index.html` with Tailwind CSS styling generated from `src/input.css`.

## Files

- `index.html` — main HTML page
- `style.css` — compiled Tailwind CSS output
- `src/input.css` — Tailwind input file
- `package.json` — npm scripts and dependencies
- `package-lock.json` — exact dependency lockfile

## Run locally

1. Install dependencies:

```bash
npm install
```

2. Start the Tailwind watcher:

```bash
npm run dev
```

3. Open `try/index.html` in your browser.
